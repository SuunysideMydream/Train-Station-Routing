# รางกรุง · Bangkok Rail Map

แผนที่รถไฟฟ้ากรุงเทพฯ และตัวหาเส้นทาง React + Vite ค้นหาด้วยชื่อไทย อังกฤษ หรือรหัสสถานี ดูจุดต่อสาย แล้วเลือกเกณฑ์จอดน้อยหรือต่อขบวนน้อยได้ค่ะ

ต้นแบบใช้ข้อมูลสถานี 12 พฤศจิกายน 2569 ครอบคลุม 7 สาย ได้แก่ BTS สุขุมวิทและสีลม, MRT สีน้ำเงิน ม่วง ชมพูสายหลัก เหลือง และ Airport Rail Link ค่ะ

## เปิดโปรเจกต์

ใช้ Node.js 22.12 ขึ้นไปค่ะ

```sh
npm ci
npm run dev
```

`npm run build` สร้างเว็บใน `dist/` ค่ะ เมื่อนำซอร์สเข้า repo ที่ branch `main` แล้วเลือก **Settings → Pages → GitHub Actions** ก็ใช้ workflow ที่แนบมา deploy ได้ค่ะ

## ข้อมูลสำหรับเพิ่มสายหรือสถานี

Excel หรือ CSV ใช้รวบรวมรายการได้ค่ะ โค้ดต้นแบบอ่านชุดข้อมูลสถานีจาก `src/bangkok-open-data.json` และคู่เปลี่ยนสายจาก `src/network.js` ค่ะ

| ตาราง | ฟิลด์หลัก |
| --- | --- |
| สาย | รหัสสาย, ชื่อไทยและอังกฤษ, ผู้ให้บริการ, สี HEX |
| สถานี | รหัสภายใน, รหัสบนป้าย, ชื่อไทยและอังกฤษ, รหัสสาย, ละติจูด, ลองจิจูด, สถานะเปิดใช้ |
| ลำดับการเดินรถ | รหัสรูปแบบการเดินรถ, รหัสสาย, ลำดับ, รหัสสถานี, ปลายทางขบวน |
| จุดต่อ | คู่รหัสสถานีพร้อมสาย, ประเภททางเชื่อม, ข้อจำกัดหรือทางออกถ้ามี |
| เวลา (เมื่อเพิ่มเกณฑ์เร็วสุด) | เวลาเดินรถต่อช่วง, เวลาเดินเปลี่ยนสาย, ข้อมูลความถี่หรือตารางรถตามช่วงเวลา |
| แนวราง (เมื่อต้องการเส้นตามรางจริง) | GeoJSON LineString ตามรูปแบบการเดินรถ และสิทธิ์ใช้ข้อมูล |

ให้ใส่คู่จุดต่ออย่างชัดเจน เช่น BTS หมอชิต N8 เชื่อม MRT สวนจตุจักร BL13 ค่ะ วงวนสีน้ำเงินมีท่าพระสองตำแหน่งในลำดับบริการ จึงแสดงการเปลี่ยนขบวนเมื่อเส้นทางข้ามระหว่างสองตำแหน่งค่ะ

เกณฑ์จอดน้อยเรียงตามจำนวนช่วงที่นั่งรถก่อน เกณฑ์ต่อขบวนน้อยเรียงตามจำนวนครั้งที่ต่อขบวนก่อนค่ะ โปรแกรมใช้เส้นเชื่อมพิกัดสถานีโดยประมาณ และคำนวณจากเครือข่ายที่รวมไว้เท่านั้นค่ะ
